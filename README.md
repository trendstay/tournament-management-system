# Сервис организации спортивных турниров

## Описание
Приложение для автоматизации проведения спортивных турниров, управления командами,
игроками, тренерами, судьями и результатами матчей.

## Структура проекта

### Пакеты:
- **model.enums** — Перечисления (`UserRole`, `SportType`, `MatchStatus`)
- **model.user** — Иерархия пользователей: абстрактный класс `User` и реализации ролей (`AdminUser`, `ManagerUser`, `CoachUser`, `RefereeUser`, `PlayerUser`)
- **model.team** — Сущность спортивной команды (`Team`), хранящая тренера (`CoachUser`), капитана и список игроков (`List<PlayerUser>`)
- **model.tournament** — Сущность турнира (`Tournament`), хранящая список команд (`List<Team>`) и главного судью (`RefereeUser`)
- **model.match** — Сущность спортивного матча (`Match`) и логика подсчёта результата
- **repository** — Интерфейсы (`UserRepository`, `MatchRepository`) и In-Memory реализации на `ConcurrentHashMap`
- **service** — Сервисы бизнес-логики (`UserService`, `MatchService`), включая многопоточную обработку матчей

### Ключевые возможности:
1. ✓ Управление пользователями разных ролей (Admin, Manager, Coach, Referee, Player / Captain)
2. ✓ Формирование команд (тренер, капитан, список игроков) и турниров (команды, судья)
3. ✓ Создание и управление матчами, генерация протоколов и турнирных таблиц
4. ✓ Многопоточная обработка коллекций матчей с именованными потоками (`ExecutorService`)
5. ✓ Поиск, добавление, удаление, вывод объектов в потокобезопасном хранилище (`ConcurrentHashMap`)
