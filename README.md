# Сервис организации спортивных турниров

## Описание
Приложение для автоматизации проведения спортивных турниров, управления командами,
участниками и результатами матчей.

## Структура проекта

### Пакеты:
- **model** - DTO/Entity классы (User, Match, Tournament, Team, SportType)
- **repository** - Слой доступа к данным (UserRepository, MatchRepository)
- **service** - Бизнес-логика (UserService, MatchService)

### Ключевые возможности:
1. ✓ Управление пользователями разных ролей (Admin, Manager, Customer)
2. ✓ Создание и управление матчами
3. ✓ Многопоточная обработка коллекций матчей
4. ✓ Поиск, добавление, удаление, вывод объектов
5. ✓ In-memory хранилище на ConcurrentHashMap
