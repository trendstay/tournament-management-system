# Сервис организации спортивных турниров

Данный сервис предназначен для управления спортивными дисциплинами, турнирами, командами, матчами и пользователями.

## Структура пакетов (com.tournament):
- `model` — классы предметной области и Enum:
    - `model.user` — абстрактный пользователь и его роли (Admin, Manager, Referee, Player).
    - `model.tournament` — модель спортивного турнира.
    - `model.team` — модель команды.
    - `model.match` — модель матча и его результатов.
    - `model.enums` — перечисления (UserRole, MatchStatus).
- `repository` — интерфейсы и in-memory хранилища данных (на базе Map).
- `service` — бизнес-логика и многопоточная обработка соревнований.
- `util` — вспомогательные утилиты.
